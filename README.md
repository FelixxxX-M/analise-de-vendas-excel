📊 Análise de Vendas com Excel

Sobre o projeto

Este projeto apresenta uma análise de vendas desenvolvida no Microsoft Excel, com o objetivo de organizar dados comerciais, calcular indicadores de desempenho e apresentar informações importantes por meio de um Dashboard.

O projeto foi desenvolvido como parte dos meus estudos em Excel e análise de dados, utilizando uma base de dados fictícia para fins de aprendizado e demonstração de conhecimentos.

🎯 Objetivos

- Analisar o faturamento total das vendas.
- Identificar os produtos mais vendidos.
- Comparar o faturamento entre categorias.
- Analisar o desempenho dos vendedores.
- Calcular indicadores importantes para o negócio.
- Apresentar os resultados em um Dashboard.

🛠️ Ferramentas e recursos utilizados

- Microsoft Excel
- PROCV
- PROCX
- SOMASE
- SOMA
- MÉDIA
- CONT.VALORES
- MÁXIMO
- Tabelas e filtros
- Formatação de células
- Gráficos e Dashboard

📈 Indicadores analisados

- Faturamento total
- Quantidade de vendas
- Unidades vendidas
- Produtos cadastrados
- Produto mais vendido
- Vendedor com maior faturamento
- Ticket médio
- Categoria com maior faturamento

📊 Visualizações do Dashboard

O Dashboard apresenta três gráficos:

1. Faturamento por categoria.
2. Quantidade vendida por produto.
3. Faturamento por vendedor.

📌 Resultados da análise

Com base nos dados fictícios utilizados no projeto, foram obtidos os seguintes resultados:

- Faturamento total: R$ 19.720,00
- Quantidade de vendas: 10
- Unidades vendidas: 24
- Ticket médio: R$ 1.972,00
- Produto mais vendido: Mouse
- Vendedor com maior faturamento: Carlos
- Categoria com maior faturamento: Informática

📁 Arquivo do projeto
